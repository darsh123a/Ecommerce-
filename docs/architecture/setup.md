# 2. AI Execution Rules

Before installing or changing anything:

1. Inspect the current environment.
2. Check whether the required software is already installed.
3. Do not reinstall software that is already correctly installed.
4. Do not overwrite existing project files unnecessarily.
5. Do not delete existing files or directories without approval.
6. Do not modify architecture documents.
7. Do not modify the reference design.
8. Do not install unnecessary dependencies.
9. Use stable production-supported versions.
10. After every major setup step, verify that it works.

If a required installation needs administrator privileges or cannot safely be automated, stop and explain exactly what the user must do manually.
